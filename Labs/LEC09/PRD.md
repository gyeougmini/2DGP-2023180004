# PRD - Sonic 애니메이션 뷰어

## 1. 개요

| 항목              | 내용                                                                       |
| ----------------- | -------------------------------------------------------------------------- |
| 목표              | `sonic-sprite.png` 의 모든 동작 애니메이션을 순서대로 무한 재생하는 뷰어 |
| 언어 / 라이브러리 | Python 3, pico2d                                                           |
| 소스 파일         | `Labs/LEC09/sonic_animation_viewer.py` (단일 파일)                       |
| 리소스            | `Labs/LEC09/sonic-sprite.png` (399 x 525 px, 배경 투명 RGBA)             |
| 브랜치            | `LEC09-animation-viewer`                                                 |

## 2. 개발 규칙

1. **단계별 개발**: 한꺼번에 작성하지 않고 6장의 단계를 하나씩 진행한다.
2. **단계당 1커밋**: 단계마다 실행해서 확인한 뒤 커밋한다. 커밋은 **최소 20개**다.
3. **커밋 메시지는 반드시 한글로 작성**한다. 6장의 "커밋 메시지"를 그대로 쓴다.

## 3. 기능 요구사항

| ID | 요구사항  | 상세                                                      |
| -- | --------- | --------------------------------------------------------- |
| F1 | 동작 재생 | 한 동작의 프레임을 왼쪽부터 순서대로 그린다.              |
| F2 | 5회 반복  | 한 동작을 처음부터 끝까지 5번 재생한다.                   |
| F3 | 1초 정지  | 5회가 끝나면 마지막 프레임을 띄운 채 1초 멈춘다.          |
| F4 | 다음 동작 | 정지가 끝나면 다음 동작의 0번 프레임부터 재생한다.        |
| F5 | 무한 반복 | 마지막 동작 다음에는 첫 동작으로 돌아간다.                |
| F6 | 확대 출력 | 원본(높이 약 27~44 px)을 4배 확대해 화면 가운데에 그린다. |
| F7 | 종료      | 창 닫기 (`SDL_QUIT`) 또는 `ESC` 키로 즉시 종료한다.   |

## 4. 화면 / 타이밍 사양

| 상수 / 항목      | 값         | 비고                               |
| ---------------- | ---------- | ---------------------------------- |
| 창 크기          | 1200 x 800 | `open_canvas(1200, 800)`         |
| 배경             | 흰색       | 투명 배경 스프라이트가 잘 보이도록 |
| `SCALE`        | 4          | 가장 큰 프레임 44 px → 176 px     |
| `CENTER_X`     | 600        | 화면 가로 중앙                     |
| `GROUND_Y`     | 300        | 바닥선 (발 기준 정렬)              |
| `FRAME_TIME`   | 0.1초      | 동작별로 조정 가능                 |
| `PAUSE_TIME`   | 1.0초      | 동작 사이 정지 시간                |
| `REPEAT_COUNT` | 5          | 한 동작 반복 횟수                  |

## 5. 스프라이트 시트 분석

프레임 크기와 간격이 **불규칙**해서 격자 계산으로 자를 수 없다. 그래서 미리 측정한 좌표를 코드에 넣는다.

### 5.1 좌표 변환

- 측정값은 이미지 편집기 기준이다 (왼쪽 위 원점, y는 아래로 증가).
- pico2d는 **왼쪽 아래가 원점**이다. 따라서 `pico_y = 525 - (top + h)` 로 바꾼다.

### 5.2 동작 목록 (재생 대상 10개)

| #  | 동작 (가칭)        | name          | 프레임 수 | pico_y | h  |
| -- | ------------------ | ------------- | --------- | ------ | -- |
| 1  | 대기               | `idle`      | 11        | 447    | 39 |
| 2  | 걷기 → 달리기     | `run`       | 12        | 407    | 39 |
| 3  | 전력 질주          | `dash`      | 6         | 362    | 42 |
| 4  | 스핀               | `spin`      | 9         | 325    | 33 |
| 5  | 구르기             | `ball`      | 6         | 292    | 27 |

## 6. 설계

### 6.1 데이터 구조

```python
ANIMATIONS = [
    {'name': 'idle', 'y': 447, 'h': 39, 'frames': [(1, 29), (31, 26), ...]},
    {'name': 'run',  'y': 407, 'h': 39, 'frames': [...]},
    ...
]
```

### 6.2 상태 변수

| 변수                         | 의미                                 |
| ---------------------------- | ------------------------------------ |
| `anim_index`               | 현재 동작 번호 (0 ~ 9)               |
| `frame`                    | 현재 프레임 번호                     |
| `repeat`                   | 현재 동작을 몇 번 재생했는지 (0 ~ 4) |
| `paused` / `pause_start` | 정지 중인지, 언제 정지를 시작했는지  |

### 6.3 상태 전이

```
[재생] frame + 1
   └─ 마지막 프레임을 지나면 → repeat + 1, frame = 0
        └─ repeat == 5 → [정지] (마지막 프레임 유지)
[정지] 1초 경과 → anim_index = (anim_index + 1) % 10, repeat = 0, frame = 0 → [재생]
```

### 6.4 메인 루프

```python
while running:
    handle_events()   # ESC / 창 닫기
    update()          # 상태 전이
    clear_canvas()
    draw()            # 현재 프레임 1장
    update_canvas()
    delay(FRAME_TIME)
```

- 1초 정지는 `delay(1.0)` 대신 `get_time()` 으로 경과 시간을 잰다. 그래야 정지 중에도 ESC가 바로 먹힌다.

### 6.5 그리기

```python
x, w = anim['frames'][frame]
image.clip_draw_to_origin(x, anim['y'], w, anim['h'],
                          CENTER_X - w * SCALE // 2, GROUND_Y,
                          w * SCALE, anim['h'] * SCALE)
```

- `clip_draw_to_origin` 은 왼쪽 아래 기준이다. 그래서 바닥선 `GROUND_Y` 가 고정되고, 가로만 프레임 폭에 맞춰 가운데 정렬한다.
